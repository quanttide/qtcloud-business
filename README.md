# 量潮商务云

## 仓库结构

```
src/studio/                – Flutter 客户端
  lib/                   – 主程序
    models/              – 数据模型（报价、合同、履约）
    screens/             – 页面层
    widgets/             – 共享组件（状态徽章等）
  assets/data/           – JSON seed 数据
  test/                  – 组件测试
docs/                      – 工作文档
  prd/                     – 产品需求文档（报价制定、合同管理、产品边界）
examples/                  – 示例与原型
```
